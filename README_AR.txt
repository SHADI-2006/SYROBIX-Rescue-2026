حزمة تسليم مشروع SYROBIX Rescue 2026 لـ Claude Code
=====================================================
1) فك الضغط عن المجلد (مثلاً إلى Documents\PlatformIO\Projects\SYROBIX_Rescue_2026)
2) افتح المجلد في VS Code أو في Claude Code (من الـ terminal: cd المجلد ثم claude)
3) الصق محتوى FIRST_PROMPT.md كأول رسالة
4) أي رسالة خطأ أو رقم قياس -> انسخها وابعتها له
ملاحظة: الكود لسا ما انبنى بالأدوات الحقيقية ولا اشتغل على الروبوت.
